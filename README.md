# rock-paper-scissors
A beginner‑friendly Python Rock–Paper–Scissors game with providing score
It is simple Python project for implementation the classic Rock–Paper–Scissors game.
#Features
Playing Rock–Paper–Scissors game against the computer
#How to Run
git clone https://github.com/your-username/rock-paper-scissors.git
cd rock-paper-scissors
python rock_paper_scissors.py
#Example
Lets play rock,paper,scissors
Enter rock, paper, scissors or Q to quit: paper
Computer picked: scissors
You lose!
Enter rock, paper, scissors or Q to quit: q
Final Score — You_wins: 0, Computer_wins: 1
Thanks for playing!
